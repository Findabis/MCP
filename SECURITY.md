# Security

Please report security problems privately to **info@findabis.com** — not in a public issue.

Include what you found, where (URL or tool name), and how to reproduce it. We'll get back to you within 5 working days.

The server is read-only and serves public directory data only. Our contact details are also published at
[`https://findabis.com/.well-known/security.txt`](https://findabis.com/.well-known/security.txt).
